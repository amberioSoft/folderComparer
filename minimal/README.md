# Мінімізована версія

Той самий застосунок, що й у корені репозиторію, але зліплений у мінімум файлів, щоб його було легко перенести вручну без гіта.

## Що переносити

| Файл | Що це |
| --- | --- |
| `FolderDiff.sln` | рішення, відкривається у Visual Studio подвійним кліком |
| `FolderDiff.csproj` | опис проєкту і два NuGet-пакети |
| `MainWindow.xaml` | усе вікно: стилі, три вкладки, шаблони діфу |
| `FolderDiff.cs` | увесь код: моделі, сервіси, вʼюмоделі, конвертери, точка входу |
| `ImageConverter.cs` | рушій пакування в PNG, узятий з imageZipper без змін |

Пʼять файлів, одна папка, без вкладених папок, разом близько 385 КБ. Плюс свій `imgkeys.txt` поруч, він у кожної машини свій і в репозиторій не входить.

## Збірка

Подвійний клік на `FolderDiff.sln` і збірка у Visual Studio, або з консолі:

```
dotnet publish -c Release -o dist
```

Потрібен .NET 10 SDK. На виході `dist\FolderDiff.exe` на 59 МБ, самодостатній, плюс копія `imgkeys.txt`.

## Відмінності від основної версії

Функціонал однаковий, різниця тільки в розкладці файлів:

- Немає `App.xaml`, замість нього `Main` у `FolderDiff.cs`, а кольори теми створює клас `Theme`.
- Три вкладки лежать прямо в `MainWindow.xaml`, а не окремими `UserControl`.
- Усі класи в одному просторі імен `FolderDiff`.

Рішення у форматі `.sln`, а не `.slnx`, щоб відкривалось і в старіших версіях студії.

Основна версія в корені репозиторію лишається розбитою по папках, правити зручніше там. Ця папка це дублікат для перенесення.
