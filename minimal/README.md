# Мінімізована версія

Той самий застосунок, що й у корені репозиторію, але зліплений у три файли коду, щоб його було легко перенести вручну без гіта.

## Що переносити

| Файл | Рядків | Що це |
| --- | --- | --- |
| `FolderDiff.csproj` | 40 | опис проєкту і два NuGet-пакети |
| `MainWindow.xaml` | 1268 | усе вікно: стилі, три вкладки, шаблони діфу |
| `FolderDiff.cs` | 3670 | увесь код: моделі, сервіси, вʼюмоделі, конвертери, точка входу |
| `ImageConverter.cs` | 4770 | рушій пакування в PNG, узятий з imageZipper без змін |

Чотири файли, одна папка, без вкладених папок. Плюс свій `imgkeys.txt` поруч, його переносити з цієї папки не треба, він у кожної машини свій.

## Збірка

```
dotnet publish -c Release -o dist
```

Потрібен .NET 10 SDK. На виході `dist\FolderDiff.exe` на 59 МБ, самодостатній, плюс копія `imgkeys.txt`.

## Відмінності від основної версії

Функціонал однаковий, різниця тільки в розкладці файлів:

- Немає `App.xaml`, замість нього `Main` у `FolderDiff.cs` і кольори теми створюються кодом у класі `Theme`.
- Три вкладки лежать прямо в `MainWindow.xaml`, а не окремими `UserControl`.
- Усі класи в одному просторі імен `FolderDiff`.

Основна версія в корені репозиторію лишається розбитою по папках, правити зручніше там. Ця папка це дублікат для перенесення.
